# 实验十：集成测试报告

## 1. 测试概述

| 项目 | 内容 |
| --- | --- |
| 测试类型 | 集成测试 / 冒烟测试 / 端到端测试 |
| 被测对象 | 模块间协作、GUI 窗口、完整业务链 |
| 测试环境 | Windows 11，Python 3.10+，PyQt6，SQLite |
| 集成方式 | 自底向上（DAO → Controller → View） |

## 2. 测试范围

1. 业务链集成（Controller 层跨模块协作）；
2. GUI 冒烟测试（5 个窗口离屏构建）；
3. 端到端登录与主窗口跳转；
4. 数据落库正确性（中文数据）。

| 场景 | 验证 | 结果 |

## 4. 集成测试结论

- 全部集成用例通过，模块间接口协作正确（预约 → 消息 → 日志 → 候补闭环）；
- 5 个 GUI 窗口离屏构建成功，界面层与业务层接线无误；
- 端到端登录与角色跳转符合预期；
- 中文数据在 SQLite 中存储正确（终端乱码仅为 GBK 显示问题，已用 `PYTHONIOENCODING=utf-8` 规避）。

**集成测试结论：通过。**
