# 实验一：软件工程实验计划

## 1. 项目概述

- **项目名称**：实验室设备预约系统
- **项目定位**：高校实验室设备在线预约与管理的独立桌面应用
- **技术选型**：PyQt6 桌面 GUI + SQLite 本地数据库 + MVC 分层架构（Python 3.10+）
- **参与角色**：学生、实验室管理员、超级管理员
- **项目目标**：解决实验室设备预约冲突、故障上报不及时、台账管理混乱等问题，实现设备预约、审核、报修、公告、统计、候补排队、站内消息、黑名单管控的全流程线上化。

## 5. 风险管理

| 风险 | 影响 | 应对措施 |
| --- | --- | --- |
| 预约冲突算法边界 | 高 | 采用开区间比较，编写边界测试用例 |

| 打包体积大 | 低 | 仅打包必要依赖，使用 PyInstaller onefile |

## 6. 验收标准

1. 系统可独立运行（`python main.py` 或双击 exe）；
2. 预约核心闭环（提交→审核→取消→爽约→候补转正）完整可用；
3. 单元测试 32 个用例全部通过，语句覆盖率 ≥80%；
4. 全套实验文档（exp1~exp11）齐备。
