## 2. 系统实现总结

### 2.1 功能实现情况

| 模块 | 核心功能 | 状态 |
| --- | --- | --- |
| 用户账号 | 注册、登录、改密、账号管理、黑名单 | ✅ |
| 设备管理 | CRUD、状态管理、浏览搜索 | ✅ |
| 预约核心 | 提交（六重校验）、审核、取消、完成、爽约 | ✅ |
| 故障报修 | 提交、处理、状态流转 | ✅ |
| 公告通知 | 发布、查看 | ✅ |
| 统计系统 | CSV 报表导出、系统日志、参数配置、备份恢复 | ✅ |
| 候补队列 | 加入、取消、取消预约自动转正 | ✅ |
| 站内消息 | 推送、消息中心、已读标记 | ✅ |

### 2.2 技术亮点

1. **MVC 严格分层**：View 不触碰数据库，业务规则集中于 Controller；
2. **预约核心闭环**：提交 → 审核 → 使用登记 → 爽约黑名单 → 取消触发候补转正；
3. **动态参数配置**：最大预约时长、黑名单阈值存于 setting 表，超管实时调整即时生效；
4. **安全设计**：bcrypt 密码哈希、角色权限隔离、关键操作留痕（sys_log）；
5. **可测试性**：DAO/Controller 支持 `db_path` 注入，工具函数支持参数注入。

## 4. 遇到的问题与解决

| 问题 | 原因 | 解决方案 |
| --- | --- | --- |
| Windows 终端中文乱码 | 控制台 GBK 编码 | `PYTHONIOENCODING=utf-8` / 重配 stdout |
| 集成测试未发现 | 命名不符 `test*.py` | 改名 `test_integration.py` |
| 学生窗口报错 | `QTableWidget.alignment()` 不存在 | 移除该调用 |
| 备份工具覆盖率 0% | 硬编码路径 | 重构为参数注入 |
| 覆盖率 77% 不达标 | utils 层未测 | 新增 `test_utils.py` → 83% |
